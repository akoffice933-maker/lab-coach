# Red vs Blue: два агента через MCP (v1.7.0)

Один сервер, два запуска с разной ролью (`AGENT_ROLE`), одна арена — сессия PlanBox.
Красный атакует по методологии, синий закрывает и меряет прогресс. Руки у человека, у агентов — план и память.

## Матрица

| Tool | red | blue | coach |
|---|---|---|---|
| `get_lab_status`, `explain_report`, сессии (`init_session`, `session_status`, `log_note`, `read_session_file`), `get_role_brief` | ✅ | ✅ | ✅ |
| `scan_lab_target`, `get_plan_step` | ✅ | ❌ | ✅ |
| `harden_checklist`, `verify_fix` | ❌ | ✅ | ✅ |
| `set_platform`, `explain_mission`, `import_scanbot_report` | ❌ | ❌ | ✅ |

Платформу задаёт человек в env. Отказ вне роли пишется в audit как `role_denied`.
Заметки подписываются ролью автоматически (`[red]`/`[blue]` в логе).

## Запуск

Два чата, два конфига. Общее: команда `python -m lab_coach.mcp`, `MCP_TRANSPORT=stdio`,
одни `ALLOWED_LAB_CIDRS`, один `HTB_DIR`. Разница — одна строка:

```json
// красный (чат 1)
{ "mcpServers": { "lab-coach-red": {
  "command": "python", "args": ["-m", "lab_coach.mcp"],
  "env": { "AGENT_ROLE": "red", "LAB_PLATFORM": "custom",
           "ALLOWED_LAB_CIDRS": "192.168.56.0/24", "HTB_DIR": "/home/kali/HTB",
           "MCP_TRANSPORT": "stdio" } } } }
```

```json
// синий (чат 2): то же, но "AGENT_ROLE": "blue"
```

Первое сообщение каждому: «прочитай свой бриф» — агент сам вызовет `get_role_brief`.

## Сценарий учения (3 раунда, ~2 вечера)

**Раунд 1 — Разведка.** Красный: `init_session(planbox, 192.168.56.110)` → ведёт тебя по шагам 0–1.
Синий в это время: `session_status` — смотрит, что уже найдено. Итог раунда: `nmap/*.txt` + `scan-*.json`.

**Раунд 2 — Атака/защита.** Красный идёт к foothold по плану. Каждая его находка —
синему: `harden_checklist("<название>")` → чек-лист закрытия. Синий чинит СТЕНД? Нет —
стенд чинить нельзя (он учебный). Синий отрабатывает чек-лист на бумаге + на своём сайте
по MAP-TO-MY-SITE, а в `notes.md` пишет `[blue] закрыл бы так: ...`.

**Раунд 3 — Замер.** Синий: `verify_fix(цель, baseline.json)` — повторный скан своей цели
против baseline. Разбор строк `[+] исправлено / [=] осталось / [!] новое`.
Критерий победы синего: ноль `[=]` по классам из чек-листов. Победа красного: оба флага + полный notes.

## Правила арены

1. Scope один на учение (`scope.txt`). Смена цели = новая сессия.
2. Агенты не выполняют команды и не ходят в сеть сами — только человек.
3. Пейлоады, входы, смена паролей — отказ у обеих сторон (так настроены брифы и слои).
4. Спор «а вот тут red должен…» решает человек-coach (третий чат с ролью по умолчанию).
